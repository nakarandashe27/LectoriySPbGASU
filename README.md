# «ИИ, сделай красиво» — визуальный черновик

Создан 05.10.2026 по прямому запросу автора собрать первую веб-презентацию с полученными материалами. **30 слайдов, десять видео.** Согласованный порядок семи разделов сохранён.

## Открыть

- Локальное превью: http://localhost:4173 (пока работает запущенный сервер).
- Можно открыть `index.html` прямо в браузере. Все семь видео упакованы в `assets/videos`, поэтому папку `presentation` можно переносить целиком. Исходники в папках проекта сохранены.
- Запустить превью отдельным скрытым процессом: `powershell -File presentation/start-preview.ps1` из корня проекта.
- Для повторного запуска сервера: `node presentation/server.cjs` из корня проекта. Node доступен также по пути `C:/Users/uvaroskyya/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe`.
- Сервер использует только адрес 127.0.0.1. Это локальное превью, ещё не публикация в интернете.

## Управление

- Кнопки снизу и стрелки клавиатуры; Home / End — начало / конец.
- Нажмите номер слайда для полного маршрута и перехода к нужному показу.
- **F** — полный экран. Заметки спикера (кнопка и **N**) — только по ссылке с `?presenter`, например `…/index.html?presenter#slide-01`; зрителям они не видны. Текст заметок всё равно лежит в открытом `slides.js`.
- Видео запускаются вручную, имеют стандартные элементы управления. При переходе загрузка предыдущего видео прекращается; при возвращении ролик открывается с начала.
- Веб-пример и 3D-объекты загружаются кнопкой внутри слайда. При уходе iframe удаляется, чтобы останавливать фоновые процессы/медиа; возвращение требует повторной загрузки. Для сохранения настроек и экспорта можно открыть объект отдельно.

## Визуальная основа

Версия 2 (05.10.2026, после замечаний автора к первому черновику). Первая версия сохранена в `../tmp/presentation-v1-codex`.

- **Брендбук** «арт.бродский студенты» (`брендбук студенты.pdf`): заголовки — Unbounded, капсом; текст — Inter Tight; чёрный `#161010`, белый, градиент `#F74C2E → #4D61F4`. Знак «а» перенесён векторно из PDF. Шрифты лежат локально в `assets/fonts` (cyrillic + latin, Google Fonts) — интернет на лекции не нужен.
- **Референс** `Rhino + Grasshopper (новое).pdf`: зернистые «нити» на обложке, капс-заголовки по центру, пилюли со стрелкой в круге, подписи по углам, тёмные карточки со светящейся сферой.
- **Живой фон** (`field.js`): тысячи частиц стягиваются к изолиниям анимированного шума и текут вдоль них. Работает на всех слайдах: тёмный — на обложках, разделах и утверждениях; светлый и приглушённый — на информационных; почти незаметный — вокруг видео. При смене слайда нити перестраиваются.
- **Интерактив**: курсор закручивает частицы и окрашивает их в фирменный градиент; клик по пустому месту даёт волну; заголовки обложек «собираются» из случайных знаков; элементы появляются по очереди; карточки наклоняются за курсором, свет внутри следует за ним.
- **Скругления**: видео, карточки, QR, варианты опроса, окна и встраивания.
- Пока ролик играет, фон замирает, чтобы не отнимать кадры у видео. При `prefers-reduced-motion` фон рисуется одним неподвижным кадром, анимации отключены.
